# Task Manager Web

A robust task management application developed as part of my **IT Career Recycling Plan**. This project bridges 20 years of professional experience with modern cloud and web development technologies.

## 🚀 Technologies
* **Language:** Python 3.x
* **Framework:** Django
* **Database:** PostgreSQL (Hosted on AWS RDS)
* **Cloud & Infrastructure:** AWS (VPC, Security Groups, SSL/TLS)
* **Environment Management:** Python-dotenv & Git Bash

## 🛡️ Key Features
* **Secure Database Connection:** Implementation of SSL/TLS using AWS root certificates for encrypted RDS communication.
* **Environment Security:** Sensitive credentials managed via environment variables (not exposed in the repository).
* **Cloud Integration:** Scalable database architecture using Amazon Web Services.

This repository tracks my progress in returning to the IT sector, focusing on modern backend development, SQL optimization, and cloud infrastructure.
